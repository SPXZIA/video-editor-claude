# Biblioteca de músicas

Crie uma pasta por clima e jogue as faixas dentro (mp3, wav, m4a…):

```
musicas/
  animada/       ← upbeat, pop, energia (bom para oferta e unboxing)
  emocional/     ← piano, cordas (bom para história e antes/depois)
  suspense/      ← tensão, build-up (bom para hook de problema)
  luxo/          ← lo-fi, jazz, elegante (bom para produto premium)
  viral/         ← sons em alta no TikTok/Reels
```

Depois rode `npm run musicas` para gerar o índice (`indice.md`) que o Claude usa para escolher.

**Onde baixar sem direito autoral:** Pixabay Music (pixabay.com/music), YouTube Audio Library
(studio.youtube.com → Biblioteca de áudio), Uppbeat (uppbeat.io, plano grátis com crédito).

Aviso: em anúncio pago no Meta/TikTok, música com direito autoral pode ser silenciada ou
bloquear o anúncio. Para anúncio, prefira as fontes acima ou a biblioteca comercial do próprio TikTok.
